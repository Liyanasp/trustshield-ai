# TrustShield AI

TrustShield AI is a full-stack demo for fraud detection and quantum risk monitoring.

## Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI

## Run locally

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
